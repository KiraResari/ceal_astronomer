# The Ceal Astronomer

A Flutter project for tracking the astronomical objects of fictional solar systems. Intended for supporting RPG campaigns where tracking the current position of planets in a solar system is important. Supports saving and loading.

Uses simplified (aka Newtonian) orbital mechanics, so maybe don't use this to plan actual astronomical missions or for anything that requires accuracy.

Currently optimized for and tested on Windows. Might work on other platforms too, but no promises. =^,~'=
